# Snapaste

独立实现的 Windows 本地截图工具，包含区域截图、对象标注、悬浮贴图、历史记录与通用纵向滚动拼接。代码不使用 Snipaste 的程序、源码、图标或资源。

**当前为 0.1.0 开发预览版，尚未达到完整替代 Snipaste 的日常稳定性验收。** 已实现的链路可以运行，但浏览器五次连续滚动、多显示器混合 DPI 等验收尚未完成；详见 [VALIDATION.md](VALIDATION.md)。

## 运行

- 推荐 Windows 11 x64；目标兼容 Windows 10 2004 / build 19041 以上，尚未在 Windows 10 实机验证。
- 便携包：解压 `artifacts/Snapaste-0.1.0-win-x64.zip`，运行其中 `Snapaste.exe`。自带 .NET 10 运行时，无需安装 SDK。
- 普通 Release：`src/Snapaste.App/bin/Release/net10.0-windows/Snapaste.exe`，需要 .NET 10 Windows Desktop Runtime。
- 默认只显示系统托盘图标。双击托盘截图；右键打开设置、历史、滚动截图或退出。再次启动会打开现有实例的设置。
- 无账号、服务器、网络请求、遥测或 AI。所有图像处理在本机完成。

## 快捷键与操作

| 按键 | 功能 |
|---|---|
| F1 | 桌面截图 |
| F3 | 剪贴板图片 / 图片文件贴图 |
| Ctrl+F1 | 选择滚动截图区域 |
| Ctrl+Alt+F3 | 显示全部贴图并恢复鼠标交互 |
| Esc | 取消选区；关闭有焦点的贴图 |
| Enter / Ctrl+C | 选区完成并复制 |
| Ctrl+S | 保存 |
| Tab（选区时） | 控件 / 窗口 / 自由模式 |
| 方向键 | 移动选区 1px；Ctrl 加速为 10px |
| Shift+方向键 | 改变选区大小 |
| C（选区时） | 复制当前鼠标像素的 HEX 颜色 |
| Ctrl+Z / Ctrl+Y | 编辑撤销 / 重做 |
| 贴图滚轮 | 围绕鼠标缩放 |
| 贴图 Ctrl+滚轮 | 透明度 |
| 贴图 R / E | 旋转 / 重新编辑 |

F1 后点击候选窗口，或拖动框选。边缘八个控制点调整选区，选区内拖动移动。双击选区或工具栏进入编辑。标注可选择、移动、右下角缩放、删除，双击文字修改；中文输入在独立普通输入窗口中完成。

贴图右键可复制、保存、旋转、翻转、调整透明度、切换置顶/穿透或关闭。穿透后使用恢复快捷键或托盘的「恢复全部贴图交互」。

## 滚动长截图

1. `F1 → 框选 → 滚动截图`，或按 `Ctrl+F1`，或使用托盘入口。
2. 框住实际滚动区域。开始后自己滚动，无需每次点击捕获；每次保留约 1/3 以上重叠，停下约 600ms 等待画面稳定。
3. 控制窗口显示实时分段预览。低可信匹配会暂停，不会静默接受。
4. 低可信时可「手动修正」，通过半透明叠加和滑块调整纵向位移；也可忽略本帧、撤销上一段或直接完成。
5. 「自动滚动」有 2.5 秒准备时间，把鼠标放回选区。鼠标离开或目标被遮挡时暂停。按暂停/继续/完成/取消控制。
6. 完成后进入相同编辑器，可标注、复制、保存或贴图。超大图片优先保存 PNG。

固定顶部/底部使用位置不变区域估计，可在会话中输入像素高度；`-1` 自动。优先在开始滚动前指定。浮动按钮与小范围动态内容在匹配时降权，**不会自动修补被悬浮物遮挡的正文**。

## 数据与构建

配置、日志、历史、贴图与滚动中间帧位于 `%LOCALAPPDATA%\Snapaste`。开发验证可通过 `SNAPASTE_DATA` 指定独立缓存目录。日志仅记录错误和匹配指标，不记录图片内容。

安装 .NET 10 SDK 后：

```powershell
dotnet restore
dotnet build -c Release
.\build.ps1 -Portable
```

单个 WPF 项目按 `Capture / Editor / Pin / ScrollCapture / Platform / Core / UI` 解耦。没有外部 NuGet 图像库；使用 Win32 可见桌面捕获、Windows UI Automation、WPF 绘制及独立实现的稳健灰度/梯度重叠匹配。滚动输出与普通截图共用 `ImageDocument` 和编辑器。

长图按文件分段保留，编辑只绘制视口内段落，PNG 按 512 行条带导出。复制/贴图/JPEG/BMP 合成限制为 6400 万像素，超过会提示保存 PNG 或裁剪。

## 已知限制

- 目前只拼接向下纵向滚动。大幅跳页、横向滚动、整屏变化或高度重复内容可能需要手动对齐。
- 只有可见桌面捕获提供器；尚未实现 WGC / PrintWindow 后备路径。不能绕过受保护视频、锁屏或更高权限窗口的限制。
- UI Automation 识别失败回退窗口；第三方提供器可能响应慢。八点调整、混合 DPI、屏幕负坐标等仍需更多真实硬件验证。
- 滚动中间帧保存在 `sessions` 目录；启动时清理七天前的会话，并按历史磁盘上限控制旧会话空间。历史和贴图有独立缓存副本。
- 文字/马赛克/模糊等已有渲染和对象编辑，但大范围高斯模糊在编辑时仍可能短暂卡顿；保存使用后台渲染线程。
- 标注工具栏进入独立编辑窗口，不是全部在桌面 Overlay 上直接编辑。可修改全局热键；编辑器内置按键和滚轮行为目前固定。
- 无分组、MSIX 安装包或完整多语言翻译；中文优先，主题与资源层已建立。
