# Snapaste

独立实现的 Windows 本地截图工具，包含区域截图、对象标注、悬浮贴图、历史记录与通用纵向滚动拼接。代码不使用 Snipaste 的程序、源码、图标或资源。

**当前为 0.8.1 开发预览版，尚未达到完整替代 Snipaste 的日常稳定性验收。** 普通截图可原位标注并提取文字。浏览器、第三方聊天/文档软件与混合 DPI 的完整验收仍待完成，详见 [VALIDATION.md](VALIDATION.md)。

## 0.8.1 文字输入实测修复

字号和字体下拉选项不再被误判为空白点击，修改后可继续输入。空白输入与回车后的新一行显示完整光标；长文字撤销或缩短后恢复自动框宽。靠屏幕边缘输入时提供可滚动的编辑区域，最终图片仍按原标注位置和截图选区输出。结束输入前先让中文输入法完成失焦处理，避免未确认候选留下空格。

本机真实鼠标和中文拼音候选已验收：椭圆内点击输入、改色/字号后续写、空白确认、旧文字重选、缩放旋转后继续输入、原生文字与对象的撤销重做，以及复制结果。详情和验收边界见验证记录。

## 0.8 点击输入与文字格式

选中文字工具（`T`）后，**单击就出现光标，可直接在椭圆、矩形内部或边线上输入**；不会拖走刚画出的图形。点击输入会自动扩展文本框，新文字接近截图右边时自动换行；仍可拖动来指定框宽。

输入前、输入中或重新选中后，均可调整字体、字号、颜色、粗体、斜体、下划线、背景、左/中/右对齐和缩进。对齐作用于文本框的内容区，不把文字自动绑定到下方图形。输入时的边框表示仍在编辑；点一次空白提交并取消选中，下一次点击才开始新的文字。`Ctrl+Enter` 提交并保留选择，`Esc` 放弃本次输入。

单击旧文字可选中后改格式、移动或变换，双击可继续编辑内容。文本格式和几何都保留为独立对象，确认后的修改可撤销/重做。输入框内的 `Ctrl+Z / Ctrl+Y` 仍使用原生文字撤销，`Ctrl+B / Ctrl+I / Ctrl+U` 切换粗体/斜体/下划线。图形与文字保持独立，移动图形不会自动带走文字。

样式操作后恢复输入焦点；旋转、翻转后重新编辑保持文字定位。新格式在截图、长图/历史/贴图编辑及导出中一致；长图/历史/贴图编辑仍使用文字对话框。0.8.1 已补充本机中文 IME 候选组合与焦点切换实测，其他输入法和混合 DPI 仍待验证。

## 0.7 智能选区与像素辅助

截图后移动鼠标，自动高亮窗口、控件或有清晰边界的面板/卡片。鼠标停下后，控件识别结果也会自动刷新；滚轮向下切到较大的候选，向上切回较小的候选，`PageDown / PageUp` 也可切换。满意时单击锁定选区，再按 `Enter` 复制；也可直接标注、识字、保存或贴图。直接拖动仍为自由框选。

`Tab` 在智能、窗口、自由模式之间切换；`Shift+Tab` 反向切换。已主动选中的较大候选，在鼠标仍位于其范围时保持，不会被晚到的控件结果抢回。截图设置中可决定默认模式。

选区边框适度加粗，并显示 `宽 × 高 px`。像素放大镜使用逐像素网格、高对比中心框，并显示选区边界、物理坐标、HEX 和 RGB；每格对应一个原图像素，按 `C` 复制颜色。调整选区边缘时也可观察放大镜。放大镜和尺寸标识不会进入输出图片。

窗口、UI Automation 和截图像素边界独立实现，不使用 Snipaste 的程序或资源。像素辅助优先识别完整、清晰、颜色较一致的矩形区域，照片、低对比或不完整边缘不保证自动识别；不能读取控件的应用会退回窗口/像素候选，也可手动框选。新控件识别与错位多屏几何已做后台验证，第三方应用鼠标交互和混合 DPI 硬件仍待实测。

## 0.6 离线文字识别（OCR）

框选后点击 **提取文字**，或按 `Ctrl+Shift+O`。结果直接出现在截图界面内，可以修改或保存为 UTF-8 文本；**复制并完成**（`Ctrl+Enter`）复制文字并退出截图，随后即可粘贴。`Esc` 返回原截图，标注和选区保持不变。长图、历史和贴图编辑视图也提供相同入口，复制后返回原编辑视图。

使用随软件附带的 PP-OCRv6 中英文多语言模型，在本机识别，不上传图片或文字，不需要账号和联网。模型在第一次识别时加载；识别可停止，长图分段处理。

默认按局部语境整理中文/英文标点，同时保护能识别的网址、邮箱、数字、版本号、路径和代码。也可选择中文标点、英文标点或还原原文；切换处理方式和手工修改均可撤销。原始识别结果始终可以展开对照，低置信度行会提示核对。

OCR 不能保证所有字体和低清图片零误差：`O/0`、`I/l/1`、罕见符号、缺损标点仍可能识别错误；规则不猜改字母数字，语境不明确的标点保留原样。仅对同一行中明显成对的中文弯引号修正开闭方向；不成对或含糊的引号及不支持的括号样式保留。重要内容应对照截图确认。

## 0.5.1 图形选择与调整

矩形、椭圆画完保持选中，可直接改色、改线宽、拖动内部移动；点图形外的空白取消选中。之后用选择工具点击内部或边线可再次修改。嵌套图形的可见笔画优先选中；取消选中后，绘图工具仍可在空心图形内部画新的标注。加粗线条和马克笔的可见边缘也能命中。上述规则在截图选区和独立编辑视图中共用，并支持撤销与重做。

## 0.5 易用性与可靠性

- 首次使用显示设置中的截图入口和三步说明；平时仍驻留托盘。设置显示实际版本，短窗口可滚动，保存按钮保持可见。快捷键冲突会标出具体操作；修改失败保留原来的可用快捷键，未改快捷键时仍可保存其他设置。
- 选中文字后改字号、颜色、粗体会作用于当前对象，字号保留小数精度。旋转或翻转后继续输入不再跳位置。文字输入中的按钮撤销与键盘撤销一致；误点、微小拖动和拖回原位不会破坏重做。撤销每个方向最多保留最近 100 步，并有 48 MiB 的几何数据预算。
- 模糊和马赛克的预览在后台以原始像素生成，与导出使用相同强度；旋转只改变遮盖范围，不会旋转底图内容。大于 1600 万像素的单个遮盖会明确提示预览失败，建议拆成较小区域。
- 历史在后台读取、分批加载缩略图；新截图会自动出现在已经打开的历史窗口。清理不会破坏正在编辑或导出的图片；损坏缓存也计入空间限制。
- 图片和贴图配置采用原子保存；文件占用或写入失败保留旧文件。主动退出时保存失败会留在应用中供重试。大贴图先适配屏幕，显示器变化后可恢复到可操作的位置。
- 长截图修复了小位移搜索、稀疏正文漏检、忽略帧重复触发及撤销后的基准恢复。出现新的固定栏证据时暂停提示检查上一段；自动滚动在切换窗口、移出选区或按住修饰键时暂停。压缩与预览解码在后台进行。

## 0.4 选中对象直接修改

刚画出的标注保持选中；点击以前的标注可重新选择。属性栏显示选中对象的颜色、线宽、字体等，修改立即生效；没有选中对象时设置下一次绘制的默认样式。线宽滑块的一次拖动可以一次撤销。

选中框提供八个调整点、顶部旋转柄（Shift 吸附到 15°），以及旋转 90°、水平翻转、垂直翻转按钮。箭头和直线有可拖动的端点，支持交换方向。矩形和椭圆在选择工具下可点击内部选择；绘图工具下，未选图形的内部仍可继续绘图。

文字可拖出输入框，左右边调整换行宽度，角点/上下边调整字号。输入后点一次空白只提交并取消选中，下一次拖动才新建输入框；单击旧文字选择，双击修改内容。颜色、字号、字体、粗体和背景均可修改已有文字。所有变换保留对象模型，并参与撤销、复制和保存；截图选区仍决定最终输出边界。

## 0.3.1 验收修复

新增 Windows 锁屏/断开会话检查，避免捕获成功却保存纯黑画面；滚动途中桌面不可用会暂停。完成/取消会话不会被后续操作改变终态，首帧取消不会回写结果。撤销同步会话文件，手动拼接同步匹配元数据。GitHub Actions 在 Windows 上编译并生成便携包。

## 0.3 原位截图标注

普通截图在桌面选区内完成标注，不再因点击绘图工具而打开独立编辑窗口。矩形、椭圆、直线、箭头、画笔、马克笔、文字、马赛克、模糊、裁剪、取色共用非破坏式对象模型；可以选择、移动、缩放、删除、撤销和重做。文字直接在选区中输入，支持字体、字号、颜色、粗体、背景与多行；`Ctrl+Enter` 确认，`Esc` 放弃当前文字。

复制、保存和贴图直接输出当前选区与标注；取消保存或输出失败保留当前操作。已有标注时开始滚动截图，会说明需要重新捕获并确认。长图、历史和已有贴图的重新编辑目前仍使用独立可滚动编辑视图。

## 0.2 界面与流程

暖灰与柔紫的明暗主题、原创线条图标，以及紧凑的截图工具栏。设置使用侧栏分类与卡片，显示未保存状态、校验错误和保存反馈。

编辑器按工具显示颜色、线宽、马赛克或模糊强度，选中工具可见；顶部区分贴图、保存、仅复制和复制并完成。支持 V/R/E/L/A/P/H/T/M/B/X/I 切换选择、矩形、椭圆、直线、箭头、画笔、马克笔、文字、马赛克、模糊、裁剪和取色。

滚动面板按捕获状态启用操作；待确认帧会显示修正与忽略入口，完成始终进入统一编辑器。固定栏设置默认收起，手动对齐可切换 100% 预览。历史按日期分组，可筛选普通/长截图与时间范围，长图缩略图显示可读的顶部内容。
## 运行

- 推荐 Windows 11 x64；目标兼容 Windows 10 2004 / build 19041 以上，尚未在 Windows 10 实机验证。
- 已发布版本见 [GitHub 预览版](https://github.com/Rinyanami/Snapaste/releases)。本地新版解压 `artifacts/Snapaste-0.8.1-win-x64.zip`，运行其中 `Snapaste.exe`。自带 .NET 10、OCR 模型和原生运行库，无需安装 SDK；本地打包不代表已经上传新版本。
- 普通 Release：`src/Snapaste.App/bin/Release/net10.0-windows/Snapaste.exe`，需要 .NET 10 Windows Desktop Runtime。
- 首次运行打开设置中的上手入口，之后默认只显示系统托盘图标。双击托盘截图；右键打开设置、历史、滚动截图或退出。再次启动会打开现有实例的设置。
- 无账号、服务器、运行时网络请求或遥测。包含本地 OCR 模型，不使用云端或生成式 AI。所有图像处理在本机完成。

## 快捷键与操作

| 按键 | 功能 |
|---|---|
| F1 | 桌面截图 |
| F3 | 剪贴板图片 / 图片文件贴图 |
| Ctrl+F1 | 选择滚动截图区域 |
| Ctrl+Alt+F3 | 显示全部贴图并恢复鼠标交互 |
| Esc | 取消选区；关闭有焦点的贴图 |
| Enter / Ctrl+C | 选区完成并复制 |
| Ctrl+S | 保存 |
| Ctrl+T（选区时） | 完成并贴图 |
| Tab（锁定选区前） | 智能 / 窗口 / 自由模式；Shift+Tab 反向切换 |
| 滚轮 / PageUp / PageDown（锁定前） | 切换较小 / 较大的候选区域 |
| 方向键 | 移动选区 1px；Ctrl 加速为 10px |
| Shift+方向键 | 改变选区大小 |
| C（选区时） | 复制当前鼠标像素的 HEX 颜色 |
| Ctrl+Z / Ctrl+Y | 编辑撤销 / 重做 |
| 贴图滚轮 | 围绕鼠标缩放 |
| 贴图 Ctrl+滚轮 | 透明度 |
| 贴图 R / E | 旋转 / 重新编辑 |

F1 后点击候选窗口，或拖动框选。选择工具下，边缘八个控制点调整截图选区；有标注选中时，点空白先取消选择，再拖动空白可移动截图选区。双击空白处完成并复制。点击绘图工具直接在选区标注，右键返回选择工具。标注可直接点选、移动、八向缩放、旋转、翻转或删除；双击文字在原位修改。方向键优先移动选中的标注，否则移动选区。中文输入使用 WPF 原生 TextBox，真实 IME 候选/组合过程仍待验收。

贴图右键可复制、保存、旋转、翻转、调整透明度、切换置顶/穿透或关闭。穿透后使用恢复快捷键或托盘的「恢复全部贴图交互」。

## 滚动长截图

1. `F1 → 框选 → 滚动截图`，或按 `Ctrl+F1`，或使用托盘入口。
2. 框住实际滚动区域。开始后自己滚动，无需每次点击捕获；每次保留约 1/3 以上重叠，停下约 600ms 等待画面稳定。
3. 控制窗口显示实时分段预览。低可信匹配会暂停，不会静默接受。
4. 低可信时可「手动修正」，通过半透明叠加和滑块调整纵向位移；也可忽略本帧、撤销上一段或直接完成。
5. 「自动滚动」有 2.5 秒准备时间，把鼠标放回选区。鼠标离开或目标被遮挡时暂停。按暂停/继续/完成/取消控制。
6. 完成后进入相同编辑器，可标注、复制、保存或贴图。超大图片优先保存 PNG。

固定顶部/底部使用位置不变区域估计，可在会话中输入像素高度；`-1` 自动。优先在开始滚动前指定。浮动按钮与小范围动态内容在匹配时降权，**不会自动修补被悬浮物遮挡的正文**。

## 数据与构建

配置、日志、历史、贴图与滚动中间帧位于 `%LOCALAPPDATA%\Snapaste`。开发验证可通过 `SNAPASTE_DATA` 指定独立缓存目录。日志仅记录错误和匹配指标，不记录图片内容。

安装 .NET 10 SDK 后：

```powershell
dotnet restore
./scripts/Get-OcrModels.ps1
dotnet build -c Release
.\build.ps1 -Portable
```

单个 WPF 项目按 `Capture / Editor / Pin / ScrollCapture / Ocr / Platform / Core / UI` 解耦。使用 Win32 可见桌面捕获、Windows UI Automation、WPF 绘制及独立实现的稳健灰度/梯度重叠匹配。OCR 使用 RapidOcrNet、ONNX Runtime、SkiaSharp 与本地 PP-OCRv6 模型；固定版本、模型校验值和许可随工程记录。滚动输出与普通截图共用 `ImageDocument` 和编辑器。

长图按文件分段保留，编辑只绘制视口内段落，PNG 按 512 行条带导出。复制/贴图/JPEG/BMP 合成限制为 6400 万像素，超过会提示保存 PNG 或裁剪。

## 已知限制

- 目前只拼接向下纵向滚动。大幅跳页、横向滚动、整屏变化或高度重复内容可能需要手动对齐。
- 只有可见桌面捕获提供器；尚未实现 WGC / PrintWindow 后备路径。不能绕过受保护视频、锁屏或更高权限窗口的限制。
- UI Automation 识别失败回退窗口；第三方提供器可能响应慢。八点调整、混合 DPI、屏幕负坐标等仍需更多真实硬件验证。
- 滚动中间帧保存在 `sessions` 目录；启动时清理七天前的会话，并按历史磁盘上限控制旧会话空间。历史和贴图有独立缓存副本。
- 模糊/马赛克预览与导出均使用后台工作线程。单个大遮盖、许多大图贴图和超多笔迹仍需长期内存与响应性测试；预览超过 1600 万像素时明确提示缩小区域。
- 滚动中首次出现的悬浮底栏可能被带入一段新内容；后续出现双帧证据后会暂停并提示撤销上一段。开始前排除会变化的工具栏，并在完成前检查预览。固定侧栏占比较大或正文过于稀疏时可能需要手动对齐。
- 普通截图支持原位编辑；长图、历史及已有贴图重新编辑仍进入独立编辑视图。可修改全局热键；内置工具按键和滚轮行为目前固定。
- 无分组、MSIX 安装包或完整多语言翻译；中文优先，主题与资源层已建立。
